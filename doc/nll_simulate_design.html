⚛️ CTPWA 设计笔记：nllSimulate —— 分波迭代的“加态 ΔNLL 模拟器”

本文是 auto-pwa 分波迭代闭环中“决定下一步该测试哪个共振态”这一环的设计笔记。 目标：在当前 best-fit 的基础上，用一次少量参数优化（而非完整冷启动拟合）， 快速估算“再加入一个共振态”能给负对数似然（NLL）带来的改变 \(\Delta\mathcal{L}\)， 从而对 PDG / 阈值附近的候选共振态做显著性排序，把重活（真拟合确认）留给最有希望的那几个。 写于 2026-08。

best-fit→ nllSimulate（快速 ΔNLL 排序）→ top-k 候选→ 试拟合确认→ 加态进下一轮
一句话结论：可行。 因为“加入单共振态”让强度对耦合是精确二次型，加上 CTPWA 已有解析梯度/解析 Hessian， “0 步得分检验 + 少步 warm-start profile”可以做到既有速度又有精度。唯一要立项修正的认知是： 在 \(\alpha=0\)（新态耦合为零）处，NLL 对 \((m,\Gamma)\) 的梯度恒为 0，所以 \((m,\Gamma)\) 必须显式扫描， 梯度公式只用于“\(\alpha\) 已铺开之后”的峰值细化。

一、NLL 的数学结构（这是整套方案便宜的根源）

CTPWA 把每个极化组态的通道振幅拼成复向量，逐事件强度成为耦合参数上的二次型：

\[ I(x;\boldsymbol{\theta}) = \sum_{\boldsymbol{\lambda}}\bigl|\boldsymbol{\theta}_a\boldsymbol{\mathcal{A}}_{\boldsymbol{\lambda}}\bigr|^2 = \boldsymbol{\theta}_a^\dagger \mathbf{B}\,\boldsymbol{\theta}_a, \qquad \mathbf{B} \equiv \sum_{\boldsymbol{\lambda}}\boldsymbol{\mathcal{A}}_{\boldsymbol{\lambda}}^*\,\boldsymbol{\mathcal{A}}_{\boldsymbol{\lambda}}^{\mathsf{T}} \tag{1} \]

\(\mathbf{B}\) 是每事件 \(N_{\rm ch}\times N_{\rm ch}\) 的 Hermitian 半正定矩阵，把该事件所有运动学/极化信息吸收进去。 于是整批数据的强度更新退化为批处理矩阵-向量积，负对数似然由结果强度的逐元素对数得到。相空间归一化矩阵预平均一次：

\[ \bar{\mathbf{B}} = \frac{1}{N_{\rm phsp}}\sum_{j=1}^{N_{\rm phsp}}\mathbf{B}_j, \tag{2} \]

这样相空间项及其导数每次迭代仅需一次 \(\mathcal{O}(N_{\rm ch}^2)\)，与 \(N_{\rm phsp}\) 无关。这是“便宜”的根源。

CTPWA 的 loss 组装（见 Analysis.cu）：

loss = data_nll − bkg_nll + (Σw_data − bkg_integral) · log(phsp_factor)
data_nll = −Σ_{data} w_e log I_e ，   I_e = Σ_polar |S_{e,p}|² ，  S = A·v

1.1 关键性质：加一条波，强度对“单个复耦合”是精确二次

在 best-fit 存在已固定的 \(S_0=A_0 v_0\)。加一条新共振态振幅列 \(A_{\rm new}\)（复耦合 \(\alpha\)）后：

\[ I_e(\alpha) = \sum_{p}\bigl|S_{0,p}+\alpha\,A_{{\rm new},p}\bigr|^2 = a_e + 2\,\mathrm{Re}[b_e\,\alpha] + c_e|\alpha|^2, \tag{3} \]

其中逐事件标量

\[ a_e=\sum_p|S_{0,p}|^2,\quad b_e=\sum_p\overline{S_{0,p}}A_{{\rm new},p},\quad c_e=\sum_p|A_{{\rm new},p}|^2. \tag{4} \]

因为只有一条新耦合，强度对 \(\alpha\) 没有更高阶项；phsp 项 \(\Phi(\alpha)\) 同样由 \(\bar{\mathbf{B}}\) 变成二次型。 这是“固定 \((m,\Gamma)\)、只优化 \(\alpha\)”时，NLL 成为 2 实参光滑函数、可闭式剖面（profile）的原因。

二、必须立项修正的物理事实：\(\alpha=0\) 处 \((m,\Gamma)\) 梯度恒为零

共振态参数梯度公式为（数据部分）：

\[ \frac{\partial\mathcal{L}_{\rm data}}{\partial\theta_r} = -2\sum_{\boldsymbol{\lambda}}\frac{1}{I_{\boldsymbol{\lambda}}} \,\mathrm{Re}\!\Big[\mathcal{P}_{r,\boldsymbol{\lambda}}\,\overline{S_{\boldsymbol{\lambda}}}\,\frac{\partial F(m;\boldsymbol{\theta}_r)}{\partial\theta_r}\Big], \qquad \mathcal{P}_{r,\boldsymbol{\lambda}}\equiv\sum_{a\in r}\theta_a[\mathcal{A}_{L,S}]_{a,\boldsymbol{\lambda}}. \tag{5} \]

对新加的共振态（此刻耦合 \(\alpha=0\)），\(\mathcal{P}_{\rm new}=\alpha\,A_{\rm new}=0\)，于是

\[ \left.\frac{\partial\mathcal{L}}{\partial m}\right|_{\alpha=0} =\left.\frac{\partial\mathcal{L}}{\partial\Gamma}\right|_{\alpha=0}=0 . \tag{6} \]
含义：新态耦合还没铺开，质量/宽度取什么值都不影响似然。因此不能从 best-fit 出发直接用 \((m,\Gamma)\) 梯度做“加态后对 \((m,\Gamma)\) 的检验”。 \((m,\Gamma)\) 必须显式网格扫描；梯度公式 Eq.(5) 用于“\(\alpha\) profile 之后、\(\alpha^*\neq0\)”的峰值细化（由包络定理，\(\partial(\min_\alpha\mathcal{L})/\partial m = \partial\mathcal{L}/\partial m|_{\alpha=\alpha^*}\neq0\)）。

三、加一个共振态 = 一组新参数（不是单个耦合）

加入一个共振态通常引入的不止一个复耦合，而是一个参数集合：

来源参数数量
每条允许的 (L,S) 分波白名单各自对应一个复耦合（Re/Im）≥1 组，视 sl 白名单而定
共振态质量 / 宽度参与拟合(m, Γ)，共享 slot0 或 2

因此单个“\(\alpha\) 精确二次 + 闭式 Schur”只是最小情形（一条波、一个复耦合、固定 \((m,\Gamma)\)），适合当 0 步快筛， 不是通用答案。通用做法是从 best-fit 出发做“有界少步参数优化”，由优化器统一处理任意多个新参数。

四、方案设计：nllSimulate = warm-start + 有界少步 profile

4.1 接口

analysis::simulateAddResonance(
  cand,            // 候选共振态 {name, J^P, chain/intermediate, model, params}
  m_grid, g_grid,  // (m, Γ) 网格（或自动从 PDG / 阈值余量取区间）
  P_mode,          // NEW_ONLY（冻住已有参数）| FULL（已有参数也允许小幅重排）
  K,               // 少步优化迭代预算（如 8–15）
  init = warm,     // 新耦合初始化为 0（或小随机）；新 (m,Γ) 初始化为网格点 / PDG
) -> { dNLL_map[m,Γ], dNLL*, (m,Γ)^, W~χ²(2), diagnostics }

4.2 算法（每个候选 × 每个 (m,Γ) 网格点）

1. 缓存 best-fit 固定量（一次）: S0 = A0·v0、phsp_matrix(M) / phsp 权重、
   data&bkg 权重、N_eff = Σw_data − bkg_integral。
2. 注入候选 R → 新增振幅列 {A_new} + 新参数集 S_new；
   初始化: 已有参数 = θ_best（warm start），新耦合 = 0，新 (m,Γ) = 网格点。
   —— 因 Eq.(6)，优化器会先长耦合、再让 (m,Γ) 动。
3. 跑 K 步优化，只对自由参数集 P 求导:
     P = S_new             → 下界（冻住已有参数）
     P = S_new ∪ θ_existing→ 完整 profile（已有参数允许小幅重排）
   每步: 解析梯度 Eq.(grad-matrix)/(grad-r) + 可选 Hessian (H_aa/H_ar/H_rr) 做阻尼牛顿;
   每步 reComputeAmps 刷新 A（主要开销，但 K 小）。
4. 记录 NLL_final 与 dNLL = NLL_final − NLL_best。

4.3 两种 ΔNLL 语义（建议都暴露）

模式自由参数ΔNLL 含义用途
NEW_ONLY仅 S_new下界（已有参数冻在 MLE）快、排序候选 / 网格
FULLS_new ∪ 已有完整 profile（加态+重拟合）与真拟合同口径，确认前用

4.4 (m,Γ) 网格扫描

粗网格→ 每点: 少步优化(仅新参, 固定本点)→ dNLL(m,Γ) 曲面→ 峰值区: 放开 (m,Γ) 少步优化→ 记录 (m,Γ)^ 与 ΔNLL^*

可选 0 步快筛：用“单 α 闭式 Schur 得分检验 \(W\sim\chi^2(2)\)”先粗排，只对少数点跑少步优化，进一步压缩成本。

五、与现有 auto-pwa 迭代链的衔接

当前 best-fit→ nllSimulate（候选 × 网格排序）→ top-1..3→ 试拟合确认（真拟合）→ compare ≥ 阈值→ add → 下一轮

放在 auto_pwa_suggest（候选发现）与 auto_pwa_try_candidates（试拟合）之间， 把“PDG / 阈值候选”先按 ΔNLL 预估快速排序，只对最有希望的几个跑真拟合。这与 try_candidates 的区别在于 warm-start + 少步（冷启需几百步），这是能做到“每候选/每网格点秒级”的关键。

六、参考：这条路线在领域里不是新东西

方案里每一块都是成熟标准做法，没有一个是新发明；新的只在“串成给 AI 用的闭环 + 用 CTPWA 二次型结构做便宜”这一层。

本方案步骤领域标准技术出处
ΔNLL 判显著似然比检验 (LRT) + Wilks 定理：嵌套模型 2ΔlogL ~ χ²(k)，k=新增自由参数Wilks 定理 / POI χ² 综述
“加态前先估 ΔNLL”Rao 得分检验 = Lagrange multiplier (LM) 检验：只用在 H₀ 处的 score + 信息阵，无需重拟合，是 LRT 的局部近似Rao score (score.stat) · Stat 8112 检验讲义
“已有参数可重排的部分”Profile / 框定参数：Schur 补 \(J_{\rm eff}=J_{\alpha\alpha}-J_{\alpha\beta}J_{\beta\beta}^{-1}J_{\beta\alpha}\) 压缩有效信息边际似然 λ_marg（框定说明）
“少量步 warm-start 收敛”从 MLE 续算 / 高斯-牛顿一步近似；MINUIT 从收敛点重启、iminuit 的 MINOS 误差标准优化器实践
(m,Γ) 网格扫描 + 显著性共振搜索 / bump hunting：扫质量取局部显著性，HEP 分波分析“逐个加态 + 扫描”的标准流程ψ(2S)→pp̄η PWA · χ_c0→π⁺π⁻K⁺K⁻ PWA
振幅分析工具ComPWA / ComPWA2、AmpTools++、TF-PWA、PAWIAN：加共振模型 + 拟合器给显著性ComPWA 文档
扫描峰值的 trials 修正look-elsewhere / trials factor：扫描 N 点后取峰不服从 χ²(k)Gross & Vitells 2010 · EPJC
结论：“没人做过”不是问题——恰恰相反，每块都有经典出处，说明路线是验证过、稳的。值得投入的是 ① 标准统计内核之上的 CTPWA 二次型向量化（便宜）、② AI 自动迭代闭环（suggest→filter→confirm→add）、 ③ 把多重耦合 / gauge 简并 / 阈值边界这些 Wilks 正则性失效的坑有意识地兜住。

8.2 两个坑被数值实锤

坑1 · 0 步得分检验：在简单模型里裸 0 步在共振处 爆掉（ΔNLL 到 −13553）甚至反向（+4706）；在增强模型里虽未爆、但也仅 +4% 精度，且仍围绕真值 ±10% 散布。 规避：主用 β 钉住的少步 profile（任何时候都是保守下界、绝不虚报），Schur 0 步当"含重拟合"的快筛；裸 0 步不要单独用（近奇异 Hessian 时会崩）。
坑2 · look-elsewhere / trials 因子：空注入扫描峰均值就有 −4.3 ~ −4.8，尾巴到 −12.5，远超 χ²(2) 的单候选阈值 −3。 规避：「ΔNLL=3」的阈值只适用于「单个固定 (m,Γ) 候选」；对 (m,Γ) 网格扫描，显著度必须用 trials 修正（空注入伪实验的扫描峰分布负尾分位，或 Gross–Vitells 解析公式）把阈值抬高，否则几乎每个空扫描都会误报成发现。该修正已在原型里验证：空注入(−5.3)被拒、真信号(−1066)被留住，分层清晰。

九、结论与下一步

可行。 设计为“从 θ_best warm-start、对新增参数集做 K 步解析优化的有界 profile”，单条 α 闭式只作为 0 步快筛和 (m,Γ) 排序加速；它与 try_candidates 的区别就在于 warm-start + 少步。 落地顺序建议：

阶段内容验证点
P0固定 β、固定 (m,Γ)：用 (a,b,c) 归约 + 2D 牛顿 profile，逐网格出 ΔNLL_map跑通“扫描-排序”闭环
P1Schur 分数检验：加 best-fit Hessian + 交叉项，输出 \(W\sim\chi^2(2)\)、\(J_{\rm eff}\) 正定诊断、\(\Delta\mathcal{L}\approx-W/2\)对齐“显著性”语义
P2粗到细网格 + look-elsewhere 修正避免把扫描峰值当真实显著性
